    전개: 스마트폰 스크린타임 분석 (30분)¶

    Part 1 — 1차시: 낯설게 보기 - 가추법 도입¶

    📌 차시 개요¶

    항목 내용
    차시 1차시 전개 파트 (7/38차시 중 해당 구간)
    주제 자기 스크린타임 데이터에서 '놀라운 사실' 발견하기
    학습목표 학생들은 자신의 스마트폰 데이터에서 숫자 기반의 놀라운 사실을 3개 이상 추출할 수 있다
    4C 역량 🧠비판적사고 (데이터를 당연하지 않게 바라보기) · 🎨창의성 (이상함을 감지하는 관점)
    준비물 교사: 시범용 스크린타임 캡처, PPT 1장 / 학생: 자기 스마트폰 스크린타임 화면, '놀라운 사실 발견 카드' 3장

    🎯 이 장에서 배우는 것¶

    • [ ] 학생이 자기 데이터에서 놀라운 사실을 3개 이상 추출하도록 지도할 수 있다
    • [ ] '놀라운 사실 발견 카드' 작성 기준을 명확히 안내할 수 있다
    • [ ] 개인차를 존중하며 순회 지도 시 맞춤 발문을 구사할 수 있다

    📚 핵심 개념¶

    개념: 놀라운 사실 발견 (Surprising Fact)¶

    1. 비유로 시작: "스크린타임 데이터를 보는 건, 자기 방을 CCTV로 돌려보는 것과 같아요. '나 이랬어?'라는 순간이 반드시 있거든요."
    2. 정의: 놀라운 사실이란 '기대와 실제 사이의 간극'이 숫자로 드러난 것입니다. 막연한 느낌이 아니라, 구체적 수치가 있어야 이상함이 선명해집니다.
    3. 예시: "카톡 메시지는 하루 10개인데, 앱을 47번 열었다" → 기대(10번쯤?)와 실제(47번)의 간극이 놀라운 사실.

    🔨 따라하기: 수업 진행 3단계¶

    Step 1: 교사 시범 보이기 (5분)¶

    💬 교사 스크립트

    "자, 선생님 스크린타임을 보여줄게요. 어제 카카오톡을 47번 열었대요. 근데 실제 온 메시지는 10개예요. 이상하지 않아요? 10개 확인하려고 47번을 열었다는 거잖아. 나머지 37번은 뭐였을까?"

    "이게 '놀라운 사실'이에요. 포인트는 숫자예요. '카톡을 많이 했다'는 이상하지 않아요. 근데 '10개 메시지에 47번 열기'는 이상하잖아요. 숫자가 있어야 이상함이 명확해져요."

    📍 교사 시범 카드 작성 (판서 또는 PPT)

    항목 내용
    관찰 카카오톡 하루 47회 열기, 실제 메시지 10개
    왜 이상한가 10개 확인에 47번은 과도함. 나머지 37번은 '혹시 왔나?' 확인
    이상함 점수 ★★★★☆ (4점)

    "이렇게 쓰는 거예요. '관찰'에는 숫자가 들어가고, '왜 이상한가'에는 '보통은 이래야 하는데 실제로는 이렇다'를 써요."

    Step 2: 학생 개인 작성 (20분)¶

    📋 활동 순서

    1. 스마트폰 스크린타임 화면을 열어 최근 일주일 데이터 확인 (2분)
    2. 놀라운 사실 발견 카드 3장에 각각 1개씩 작성 (15분)
    3. 3장 중 이상함 점수가 가장 높은 1장에 ★ 표시 (3분)

    💬 활동 안내 스크립트

    "지금부터 20분 동안 여러분 스크린타임을 열어볼 거예요. 카드 3장을 채워야 해요. '이상한 거 없는데?'라는 생각이 들 수 있어요. 그건 아직 숫자를 안 봐서 그래요. 일단 1위 앱부터 열어보세요."

    ⚠️ 예상 어려움 & 순회 지도 발문 5가지

    학생 반응 교사 맞춤 발문
    "이상한 거 없는데요" "1위 앱 하루 평균 사용 시간이 몇 분이야? 그거 수업 몇 교시 분량인지 계산해봐."
    "유튜브 많이 본 건 아는데요" "한 번 열 때 평균 몇 분이야? 그 숫자가 네 예상이랑 같아?"
    "다 비슷비슷해요" "주중이랑 주말 비교해봐. 어떤 앱이 가장 큰 차이가 나?"
    카드에 느낌만 씀 (숫자 없음) "지금 쓴 거에 숫자를 하나만 넣어봐. '많이'가 정확히 몇 분이야?"
    빠르게 3장 다 채운 경우 "그 중에 친구한테 말하면 '진짜?'라고 할 만한 게 뭐야? 그게 이상함 점수 5점짜리야."

    Step 3: 모둠 공유 및 투표 (5분)¶

    "카드 3장 중 ★ 붙인 1장을 모둠 안에서 돌려봐요. 가장 '진짜?' 소리가 나온 카드에 스티커를 붙여주세요."

    단계 교사 학생
    1 "★ 카드를 모둠원에게 보여주세요" 각자 카드를 책상 위에 놓음
    2 "30초씩 읽고, 가장 놀라운 카드에 스티커 1개" 다른 사람 카드를 읽고 스티커 부착
    3 "스티커 가장 많은 카드, 한 문장으로 소개해주세요" 모둠 대표 발견 공유

    📄 활동지: 놀라운 사실 발견 카드¶

    ┌─────────────────────────────────────────────┐
│ 🔍 놀라운 사실 #___                          │
│                                             │
│ 관찰: ________________________________       │
│ (내가 본 사실 그대로. 숫자가 꼭 들어가야 해요)    │
│                                             │
│ 왜 이상한가: _____________________________    │
│ (보통은 ___인데, 실제로는 ___이다)              │
│                                             │
│ 이상함 점수: ☆☆☆☆☆ (1~5)                    │
│ (많은 사람이 모를수록, 설명이 안 될수록 높은 점수) │
└─────────────────────────────────────────────┘

    📊 평가 루브릭¶

    평가 요소 상 중 하
    숫자 활용 3장 모두 구체적 수치 포함 1~2장에 수치 있음 수치 없이 느낌만 기술
    이상함 인식 기대와 실제의 간극을 명확히 서술 간극은 있으나 모호함 "그냥 많아요" 수준
    참여도 3장 완성 + 모둠 공유 적극 참여 2장 이상 작성 1장 이하 또는 미참여

    ⚠️ 주의할 점¶

    1. 스크린타임 미설정 학생 대비: 사전 안내로 전날 설정하게 하거나, 교사가 준비한 샘플 데이터 카드 3종을 배부하세요. 개인정보 부담 없이 활동 가능합니다.
    2. 비교·놀림 방지: "남의 숫자에 반응하는 건 좋지만, '너 중독이다' 같은 말은 금지예요. 우리는 탐정이지 판사가 아니에요."

    ✅ 점검하기¶

    1. 학생 카드에 숫자가 포함되어 있나요?
    확인 포인트"많이", "자주" 같은 부사만 있으면 미달. 반드시 분/회/개 등 단위가 있는 숫자가 필요합니다.
    1. '왜 이상한가' 칸에 기대와 실제의 대비가 드러나나요?
    확인 포인트"보통은 ~인데 실제로는 ~이다" 구조가 보이면 합격. "그냥 많아서"는 추가 발문이 필요합니다.

    💡 수업 TIP¶

    • 시간 조절: 학생 작성(Step 2)이 핵심입니다. 시범을 3분으로 줄이더라도 작성 시간은 절대 깎지 마세요.
    • 분위기 전환 한마디: 활동 시작 전 "지금부터는 탐정 모드예요. 여러분 폰이 범행 현장이고, 스크린타임이 CCTV 기록이에요"라고 말하면 몰입도가 올라갑니다.
