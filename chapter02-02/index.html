    도입: 가추법 공식 명시적 소개 (5분)¶

    📌 차시 개요¶

    항목 내용
    차시 2차시 도입 (11/38)
    주제 가추법 공식 명시적 소개
    학습목표 교사는 셜록 홈즈 비유로 가추법 공식을 학생에게 전달할 수 있다
    4C 역량 🧠 비판적 사고
    준비물 교사: PPT(3단 비교표 슬라이드) / 학생: 없음

    🎯 이 장에서 배우는 것¶

    • [ ] 셜록 홈즈 비유로 가추법을 설명할 수 있다
    • [ ] 연역·귀납과의 차이를 한눈에 전달할 수 있다
    • [ ] '틀려도 되는 추론'이라는 심리적 안전감을 형성할 수 있다

    📚 핵심 개념: 가추법 공식¶

    3단 비교표 (PPT 1장)¶

    추론 출발점 방향
    연역 규칙이 있다 → 사례에 적용 필연적 결론
    귀납 사례가 많다 → 패턴 추출 개연적 규칙
    가추 놀라운 사실 → "만약 X라면 설명된다" 가능한 가설

    가추법 공식 (PPT 2장)¶

    놀라운 사실 발견 → "만약 [가설]이 참이라면, 이 사실이 당연해진다" → 검증

    🎯 수업 흐름 (5분)¶

    시간 교사 활동 학생 활동 유의점
    0-2분 셜록 홈즈 비유 PPT 제시 + 스크립트 전달 듣기 이미지 활용 시 몰입도 ↑
    2-4분 3단 비교표 보여주며 차이 설명 비교표 확인 가추법 칸을 강조 표시
    4-5분 심리적 안전감 멘트 고개 끄덕임 이 멘트가 핵심!

    💬 교사 스크립트¶

    "지난 시간에 너희가 이상한 점을 발견했잖아. 사실 셜록 홈즈도 똑같이 해. 홈즈는 범인을 보고 추리하는 게 아니야. '이상한 점'을 먼저 발견하고, 그걸 설명할 수 있는 가설을 세우는 거야."

    "이걸 정리하면 이런 공식이야. (PPT) 놀라운 사실 → '만약 이래서라면 설명이 되지 않을까?' → 검증. 이게 가추법이야."

    "중요한 건 — 가설은 여러 개 세워도 되고, 틀려도 돼. 틀리면 다음 걸 시도하면 되는 거야. 오늘 너희가 할 일이 바로 이거예요."

    ⚠️ 주의할 점¶

    • 비교표를 외우게 하지 말 것 — 감각적으로 이해하면 충분
    • "틀려도 된다"는 멘트를 반드시 포함 — 이후 가설 활동의 심리적 토대

    ✅ 점검하기¶

    1. 학생들이 "놀라운 사실 → 가설 → 검증" 흐름을 말로 따라 할 수 있는가?
    확인 방법"방금 공식 세 단계가 뭐였지?" 라고 물어 학생 1명이 답하면 OK
    1. "틀려도 된다"는 메시지가 전달되었는가?
    확인 방법학생 표정이 편안하고, 이후 가설 활동에서 망설임 없이 쓰기 시작하면 성공
